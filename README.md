# Unity

Dos juegos hechos con Unity y C#.

## Juego3D

Parkour en primera persona. Hay que recoger monedas hasta llegar a 50 puntos sin caer en las zonas de muerte. El personaje camina, corre y salta con físicas de Rigidbody, y el juego tiene menú principal y pantallas de victoria y derrota.

## Scripting

Juego 2D. Te mueves por el mapa recogiendo monedas hasta llegar a 120 puntos mientras esquivas bombas y enemigos que te persiguen. Tiene puntos, vidas, sonidos y pantallas de victoria y game over.

## Cómo abrirlos

Abre la carpeta `Juego3D` o `Scripting` desde Unity Hub. `Juego3D` está hecho con Unity 2021.3.
